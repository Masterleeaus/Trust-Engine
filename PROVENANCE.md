# Provenance

## What this repository contains

`Masterleeaus/Trust-Engine` contains the extracted **Titan Trust Master v2.1.0** extension source for the Titan Zero/MagicAI Laravel host. `extension.json` is the canonical package manifest for the extension name, version, provider, installation contract, and integrity entries. `README.md` documents the implemented evidence-assurance architecture and its AI/agent boundary.

## Source history

- The public repository was published as a source extraction; the extension files remain at the repository root so the host installer layout is recognizable.
- The source ZIP and temporary deployment notes were removed in an earlier cleanup to avoid duplicating the package in Git. The extracted source, manifests, evaluation corpus, committed results, and branded assets remain.
- The repository history records the publication and cleanup commits, including [Publish Titan Trust Engine source and branded documentation](https://github.com/Masterleeaus/Trust-Engine/commit/74303478e4a66ea51f8270de34b022968e619751).
- This record describes repository provenance; it does not assert original authorship of every extracted file. `Masterleeaus` is the current GitHub repository owner and committer for this public mirror.
